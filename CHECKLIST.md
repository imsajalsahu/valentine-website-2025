### 🎨 Customization You Can Do

#### Change the Image (EASY)
1. Open `index.html`
2. Find line ~45: `<img id="valentineImage" src=...`
3. Replace the URL with your image
4. Save and refresh

**Best image sources:**
- Your own photos of you two
- Unsplash.com (free romantic images)
- Pexels.com (free photos)
- Your phone's photo library

#### Change Messages (EASY)
1. Open `config.js`
2. Look for the `questions` object
3. Edit the text strings
4. Save and refresh

#### Change Colors (EASY)
1. Open `config.js`
2. Look for the `colors` object
3. Update hex color codes
4. Save and refresh

**Color resources:**
- colorhunt.co
- coolors.co
- colormind.io

#### Add More Popup Messages (MEDIUM)
1. Open `script.js`
2. Find `const popupMessages = [`
3. Add new objects to the array:
   ```javascript
   { title: "Your Title! 💕", message: "Your message here!" }
   ```
4. Save and refresh
