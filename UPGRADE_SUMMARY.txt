## 💻 TECHNICAL MAGIC:

**No Button Tracking Algorithm:**
```
1. Mouse moves anywhere on page
2. For each No button:
   - Calculate distance = √(dx² + dy²)
   - If distance < 100px:
     - Calculate escape angle = atan2(dy, dx)
     - Move button 120px in that direction
     - Clamp to viewport boundaries
     - Use position: fixed for global tracking
3. Repeat on every mouse movement
```

**Question Progression:**
```
1. Q1-3, Q5: handleYesClick() → showNextQuestion()
2. Q4: Love meter flow
3. Q6: celebrate() with special effects
```

**Celebration Effects:**
```
1. Show popup for 2.5 seconds
2. Create 80 hearts with random properties
3. Create 15 sparkles immediately
4. Repeat sparkle creation every 800ms
5. Hearts float for 3-8 seconds
6. Sparkles float for 5 seconds
7. Auto-remove after timeout
```
