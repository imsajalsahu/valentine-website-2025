## 🎨 CUSTOMIZATION (Super Easy!)

### Change the Image (2 minutes)
```
1. Find a romantic photo (you two together!)
2. Open index.html
3. Find: <img id="valentineImage" src="..."
4. Replace URL with your image
5. Save and refresh
Done! 📸
```

### Change Messages (5 minutes)
```
1. Open config.js
2. Find: questions { first { text: ...
3. Edit the text strings
4. Save and refresh
Done! 💌
```

### Change Colors (3 minutes)
```
1. Open config.js
2. Find: colors { backgroundStart: ...
3. Update hex color codes
4. Save and refresh
Done! 🎨
```

### Add More Popups (5 minutes)
```
1. Open script.js
2. Find: const popupMessages = [

4. Save and refresh
Done! 💬
```
