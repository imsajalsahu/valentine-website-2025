## 🎨 Customization Options (If Needed)

### Change the Image
Edit `index.html` around line 45:
```html
<img id="valentineImage" src="YOUR_IMAGE_URL" alt="You are beautiful">
```

### Change Questions
Edit `config.js` - find the `questions` object and update text

### Change Colors
Edit `config.js` - find the `colors` object and update hex codes

### Add More Popups
Edit `script.js` - find `popupMessages` array and add more

### Change Celebration Message
Edit `config.js` - find the `celebration` object
